# Semantic HTML5 & Accessible Component Architecture

An accessible enterprise dashboard structure built using semantic HTML5 and WCAG-focused practices.

## Project Structure

- `index.html` - Main dashboard page
- `pages/` - Additional dashboard pages
- `components/` - Reusable accessible HTML components
- `css/` - Dashboard styling
- `js/` - JavaScript functionality

## Accessibility Features

- Semantic HTML5 elements
- Accessible navigation
- Proper heading hierarchy
- Table captions and column scopes
- Labels associated with form controls
- Required and validation attributes
- Keyboard focus indicators
- Accessible dialog structure
- Responsive layout

## Pages

- Dashboard
- Users
- Reports

## Validation

The main HTML pages were checked using the W3C Nu HTML Checker with zero validation errors.
